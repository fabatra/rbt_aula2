Nível 2: Tomada de Decisão (if / elif / else)

Intermediário

O robô precisa tomar decisões! Usamos condições numéricas para saber se o carrinho deve acelerar ou parar.

# Exemplo Nível 2: distancia = float(input("Digite a distância do obstáculo (cm): ")) if distancia <= 10.0: print("🛑 PERIGO: Parar motores!") elif distancia <= 30.0: print("🟡 ATENÇÃO: Reduzir velocidade.") else: print("🟢 LIBERADO: Caminho livre.")

🎯 Desafio Nível 2:

Nível 3: Repetição Contínua (while True e break)

Avançado

Para o robô ficar vigiando a porta continuamente, usamos um loop infinito. O comando break serve como botão de emergência!

# Exemplo Nível 3: while True: comando = input("Digite 'parar' para desligar o robô ou 'rodar' para continuar: ") if comando == "parar": print("🤖 Robô desligado com segurança.") break print("🚚 Robô em movimento...")

🎯 Desafio Nível 3:

Crie um loop que continue rodando até que o usuário digite a senha correta "1234" para liberar o carrinho.

Testar no Compilador 💻

Nível 4: Proteção contra Falhas (try / except e random)

Pro

O tratamento de exceções impede que o robô trave se o usuário digitar letras no lugar de números. O módulo random sorteia valores aleatórios.

# Exemplo Nível 4: import random entrada = input("Digite a leitura do sensor (número): ") try: valor = int(entrada) print("✅ Leitura válida:", valor, "cm") print("🎲 Sorteio de rota alternativa:", random.randint(1, 3)) except ValueError: print("⚠️ ERRO: Digite apenas números inteiros!")

🎯 Desafio Nível 4:

Combine o try/except dentro de um while True para obrigar o usuário a digitar um número válido sem que o programa quebre.

# Exemplo Nível 5 (Projeto Integrador): # Termos de Fibonacci: 1, 1, 2, 3, 5 padrão_fibonacci = print("🔔 Simulador da Campainha Acessível para Surdos") for piscadas in padrão_fibonacci: print("⚡ LED pisca", piscadas, "vez(es) no ritmo visual...") print("✅ Sinalização concluída!")
